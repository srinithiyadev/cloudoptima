Frequently Asked Questions

Is CloudOptima really free?
Yes! CloudOptima is completely free and open-source. No hidden costs, no credit card required.
Which clouds are supported?
AWS (real data), Azure (mock), and GCP (mock). You can connect your real AWS account to see actual resources.
Is my cloud key secure?
Yes. Keys are stored locally and sent directly to AWS API. We never store your secrets.
What are idle resources?
Resources running but not being used (low CPU, no traffic). They waste money.
Can I use this for my college project?
Absolutely! CloudOptima was built for students. The code is on GitHub.
